# File Share

Firebase 없이 현재 같은 방에 접속해 있는 사용자끼리 파일을 공유하는 웹앱입니다.

## 작동 방식

- 파일 자체는 서버에 업로드하지 않습니다.
- PeerJS를 이용해 WebRTC 연결을 만들고, 파일은 사용자 기기 사이에서 직접 전송합니다.
- 방의 접속자 목록도 현재 연결된 사용자 기준으로만 표시됩니다.
- 방의 호스트가 나가면 해당 방은 종료됩니다.
- GitHub Pages 같은 정적 호스팅에서 실행할 수 있습니다.

## 사용법

1. 닉네임과 방 코드를 입력합니다.
2. **방 입장**을 누릅니다.
3. 같은 방 코드를 다른 사람에게 알려줍니다.
4. 다른 사람이 들어오면 접속 중인 사용자 목록에 표시됩니다.
5. 파일을 선택하거나 끌어놓으면 현재 연결된 사용자들에게 직접 전송됩니다.

## 주의

WebRTC 연결을 위한 시그널링에는 PeerJS의 공개 서버를 사용합니다. **파일 내용은 PeerJS 서버에 저장하지 않고 P2P 데이터 채널로 전송**됩니다.

대용량 파일은 브라우저 메모리와 네트워크 상태에 따라 전송 속도와 안정성이 달라질 수 있습니다.
